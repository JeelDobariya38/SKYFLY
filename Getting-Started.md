\## How to run project.



1\. run Apache \& MySQL in xampp. MySQL port is 3306

2\. clone repository or download zip from GitHub...

3\. unzip \& open project OR directly import zip in netbeans.

4\. click project in left side and build with dependencies.

5\. then click run and everything is done.

6\. run the sql file for get dummy data. file is inside database folder for a big dummy data.



Note:- if get a port error just close netbeans and change port in .env or application.properties.
